
# Changelog

В этом файле ведется учет изменений проекта

Формат основан на [стандарте формата CHANGELOG](https://keepachangelog.com/en/1.0.0/),
и придерживается [правил версионирования](https://semver.org/spec/v2.0.0.html).

- Реализовано:
    - Валидация типов данных введенных параметров на уровне HTTPRouterInterface
    - Класс ресурса (Resource)
    - Контракт фабрики валидаторов (ValidatorFactoryInterface) и его реализация (ValidatorFactory)
    - Контракт валидатора (ValidatorInterface)
    - Правило валидации булевых значений (BooleanRule)
    - Правило валидации чисел с плавающей точкой (FloatRule)
    - Правило валидации целых чисел (IntegerRule)
    - Правило валидации строковых значений (StringRule)
    - Контракт для работы с базой данных и подключения к ней
    - Контракт построителя запросов
    - Контракт фабрики объектов соединения с базой данных
    - Фабрика объектов соединения с базой данных
    - Объект соединения с базой данных mariadb
    - Объект построителя запросов для базы данных mariadb
    - Объект соединения с базой данных в виде файлов json
    - Объект построителя запросов для базы данных в виде файлов json
    - Контракт формы валидации тела запроса
    - Абстрактный класс формы валидации тела запроса по контракту, инкапсулирующий логику валидации
    - Контракт фабрики создания объектов формы валидации тела запроса
    - Объект динамической формы валидации тела запроса
    - Абстрактный контроллер для инкапсуляции механизмов управления ресурсом
    - Мидлвеер валидации запрооса по по OpenApi спецификации
    - Правило валидации значений по регулярному выражению (RegexRule)
    - Правило валидации обязательных значений (RequireRule)
- Изменено:
    - Добавлен метод регистрации ресурса в контракт HTTPRouterInterface (изменен Router в соответствии с контрактом)
